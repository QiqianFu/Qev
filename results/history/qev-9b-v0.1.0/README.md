# Qev-9B v0.1.0 results

This archive preserves the original 9B benchmark table, all 231 public JevBench predictions, evaluation metadata and training configuration. Its MMLU-Pro accuracy is 54.60%; public JevBench accuracy is 188/231 (81.39%).

The original weights remain available as [AustinFu/Qev-9B@v0.1.0](https://huggingface.co/AustinFu/Qev-9B/tree/v0.1.0). This is the teacher used for the released Qev-2B. Current Qev-9B results are in [the main results table](../../benchmarks.json).
