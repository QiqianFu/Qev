# Qev-9B v0.2.0 results

This snapshot preserves the previous 9B release: all 4,459 Principle judgments and 600 boundary questions in the main set, with 1,783 late records. Its selected checkpoint is step 2643, with MMLU-Pro 57.40% and JevBench 192/231 (83.12%).

The original weights remain available at [AustinFu/Qev-9B@v0.2.0](https://huggingface.co/AustinFu/Qev-9B/tree/v0.2.0). The benchmark tables, Decision Index scores, per-question JevBench predictions, evaluation metadata and training configuration here are unchanged snapshots from that release. Current results are in [benchmarks.json](../../benchmarks.json).
